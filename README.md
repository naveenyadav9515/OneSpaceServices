# OneSpaceServices
Personal dashboard - Backend Repo

> One-Space backend API powering real-time expense tracking and Gmail sync.

## Overview
OneSpaceServices is the backend service powering the OneSpace dashboard, providing RESTful APIs for:
- Expense Tracking & Analytics
- Gmail Transaction Synchronization
- Rental Collection Management
- User Authentication & Profile Settings

### API Documentation
Interactive Swagger documentation is available at `/api-docs` when the server is running.
